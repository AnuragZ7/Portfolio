# Anurag Kumar | Portfolio

Responsive personal portfolio built with React and Vite.

## Features
- Reusable React sections and data-driven skill/project cards
- Responsive mobile navigation with accessible expanded state and Escape-to-close
- Interactive project filters for Full-stack and AI / ML projects
- Responsive desktop, tablet, and mobile layouts
- Reduced-motion support and keyboard-visible focus states
- LinkedIn, GitHub, email, and phone contact links

## Run locally
Requires Node.js 20.19+ or 22.12+.

```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Structure
- `index.html` — Vite HTML entry point
- `src/main.jsx` — React application entry point
- `src/App.jsx` — portfolio sections and interactive React state
- `style.css` — styling and responsive breakpoints
